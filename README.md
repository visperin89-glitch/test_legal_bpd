# Портал тестування юристів системи БПД

🌐 **Робочий сайт:** https://visperin89-glitch.github.io/test_legal_bpd/

Вебпортал для перевірки знань законодавства, внутрішніх порядків та правил роботи в системі надання безоплатної правничої допомоги.

## Основний функціонал

- **Модульне тестування (Lazy Loading):** миттєве відкриття порталу із завантаженням запитань лише для обраного модуля.
- **Об'єднаний іспит:** паралельне підвантаження всіх активних модулів та формування випадкової вибірки до 20 запитань із перемішуванням варіантів відповідей.
- **Таймер та античит:** зворотний відлік на 20 хвилин із автоматичним завершенням, заборона виділення тексту, копіювання, контекстного меню та гарячих клавіш під час іспиту.
- **Світла та темна тема оформлення:** перемикач у шапці, на екрані тестування, результатів та в адмін-панелі зі збереженням вибору в `localStorage`.
- **Панель адміністратора:** керування видимістю й назвами модулів, створення нових модулів, пошук та редагування запитань, імпорт/експорт JSON і збереження автономної версії HTML.
- **Фіксація результатів та досьє:** автоматичне надсилання результатів до Google Таблиць через вебхук і генерація детального звіту-досьє у форматі Word (`.doc`) та для друку.

## Структура проєкту

```text
.
├── index.html                 # Головний інтерфейс та логіка порталу (React + Tailwind CSS)
├── README.md                  # Документація проєкту
├── assets/                    # Оригінальні логотипи БПД
│   ├── white.png              # Білий логотип для темних і зелених фонів
│   ├── color.png              # Кольоровий логотип (світла тема, favicon, Word/друк)
│   └── black.png              # Монохромний чорний логотип
└── data/                      # Модульна база запитань (Lazy Loading)
    ├── manifest.js            # Метадані та перелік модулів
    ├── mod_law.js             # Модуль 1: Закон України «Про безоплатну правничу допомогу»
    ├── mod_org.js             # Модуль 2: Порядок організації та надання БПД
    ├── mod_emp.js             # Модуль 3: Порядок надання БВПД працівниками
    ├── mod_constitution.js    # Модуль 4: Знання Конституції України
    ├── mod_rec.js             # Модуль 5: Правила організації прийому клієнтів
    └── mod_kias.js            # Модуль 6: Робота з КІАС
```
